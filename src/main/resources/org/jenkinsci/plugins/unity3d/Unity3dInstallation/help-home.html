The platform independent Unity or Tuanjie Editor installation path. The plugin automatically detects the editor executable below this directory. It looks for Editor/Unity.exe or Editor/Tuanjie.exe on Windows, Contents/MacOS/Unity or Contents/MacOS/Tuanjie on Mac, and the corresponding executable below Editor on Linux.

When the editor was installed by Unity Hub or Tuanjie Hub, select the root directory of the specific editor version, not the Hub application itself. This plugin launches an already installed editor; it does not discover versions from Hub or install editors and modules.

This field is optional on the Jenkins controller if you do not intend to build on the controller. Do not forget to configure the location of the installations on your nodes as needed.

You may use environment variables in the path and define those variables wherever you feel like (master, node, job). The final installation path will be resolved at job execution time.
